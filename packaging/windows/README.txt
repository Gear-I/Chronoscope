Chronoscope for Windows (alpha)
===============================

No installation or Python is needed. Keep this whole folder together: the two programs
share the files in _internal.

  Chronoscope.exe       The desktop app. Drop a case folder onto it to open that case.
  chronoscope-cli.exe   The command line. Run it from PowerShell or Command Prompt, for
                        example:  .\chronoscope-cli.exe --help

Windows SmartScreen may warn that the app is from an unknown publisher, because this alpha
is not code-signed. Choose "More info" and then "Run anyway" if you trust the download.
Check the zip's SHA-256 against the one on the release page first.

This is an alpha: check results against a second tool before relying on them, and never
use it as the only tool on live casework.
